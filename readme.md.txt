# Spiral Distribution Engine

Motor de distribuição oficial da Spiral Codes.

## Requisitos

- Node.js 24+
- Git

## Instalação

```bash
git clone https://github.com/reimsfreitas-alt/spiral-distribution-engine.git
cd spiral-distribution-engine
npm install
```

## Configuração

Criar:

```
config/credentials.json
config/tokens/
.env
```

Esses arquivos NÃO fazem parte do repositório.

## Executar

```bash
node src/cli.js
```

## Status

```bash
node src/status.js
```

## Estrutura

```
src/
config/
campaigns/
assets/
logs/
publish/
```
